# Poker Freeroll Value Calculator

A simple browser-based tool for estimating the average value of a poker freeroll tournament.

The calculator helps compare freerolls by using the total prize pool, number of participants and entry cost.

## What the tool calculates

Enter:

- Prize pool
- Number of players
- Entry cost

The tool calculates:

- Average prize pool value per player
- Entry cost
- Estimated value after entry cost

## Example

If a tournament has:

- Prize pool: $1,000
- Players: 500
- Entry cost: $0

The average prize pool value per player is:

`$1,000 / 500 = $2.00`

For a true freeroll with no entry cost, the estimated value is therefore $2.00 per participant.

## Disclaimer

This calculator provides a simplified mathematical estimate only.

Actual expected value depends on tournament structure, payout distribution, number of entrants, player skill and other factors. The calculated result should not be treated as a prediction of winnings.
